## Getting Started

1. Run `npm install`
2. Run `npm run dev`

## Supabase persistence (shared birthday board)

Windows and their content persist to Supabase and sync live between guests. To
enable it:

1. Create a Supabase project at https://supabase.com.
2. In the dashboard, open **SQL Editor → New query**, paste the contents of
   [`supabase/setup.sql`](supabase/setup.sql), and run it. This creates the
   `desktop_windows` table, realtime publication, RLS policies, and the
   `desktop-media` storage bucket.
3. Copy your **Project URL** and **anon / public** key (Settings → API, or the
   **Connect** button) into a `.env` file (see `.env.example`):

   ```
   VITE_SUPABASE_URL=https://<project-ref>.supabase.co
   VITE_SUPABASE_ANON_KEY=<anon-public-key>
   ```

4. Restart `npm run dev`.

Without these env vars the app runs **offline** — windows work in-memory but
nothing is saved. Ownership is soft (per-browser id in localStorage): you can
only move, edit, or close windows you created.
